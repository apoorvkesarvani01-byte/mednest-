## 🌟 Problem Statement & Solution

Traditional healthcare in India is deeply fragmented:
1. **Emergency delays:** Finding available ICU beds, ALS ambulances, or specific blood groups during golden hours requires panic calling multiple facilities.
2. **Disjointed treatment:** Diagnostic records, prescriptions, and physician notes are scattered across paper files and siloed hospital apps.
3. **The Discharge Cliff:** When patients leave the hospital, they enter a void of uncoordinated home care: finding trustworthy caregivers, sourcing sanitized ICU beds or oxygen equipment, managing complicated medication schedules, and keeping family members updated.

### 💡 The MEDNEST Solution
MEDNEST bridges every stage through a single unified coordination layer:
$$\text{Emergency Response} \longrightarrow \text{Inpatient / OPD Treatment} \longrightarrow \text{Hospital Discharge} \longrightarrow \text{MEDNEST Care (Home Recovery)}$$

## ✨ Key Platform Features

- 🚨 **24/7 Rapid Emergency Response Hub:** Real-time triage uniting **Trauma Hospitals (ICU beds)**, **GPS-Tracked ALS/BLS Ambulances (8m ETA)**, and **Live Blood Bank Stocks (A+, B+, O+, AB+)**.
- 🏥 **Healthcare Marketplace Discovery:** Multi-specialty hospital discovery with verified NABH/NABL credentials, live wait-times, distance, and 1-click directions.
- 👨‍⚕️ **Verified Doctor Discovery:** Top specialists (Cardiology, Orthopedics, Neurology, Pediatrics, Pulmonology, General Medicine) with transparent fee structures and slot pickers.
- 🧪 **Diagnostic Test Hub:** NABL accredited labs with **Free Home Sample Collection** (CBC, MRI, CT Scan, Ultrasound, Lipid Profile, Thyroid, HbA1c) and 6-hour digital reports.
- 💊 **Licensed Pharmacy & Prescription Support:** Genuine medications fulfilled by licensed neighborhood chemist partners, instant prescription upload scanner, refill reminders, and strict non-substitution safeguards.
- 💖 **MEDNEST Care™ (Flagship Differentiator):** *“Care Doesn't End at Discharge.”* 9 comprehensive post-discharge modules: ICU Nurses, Home Physiotherapists, Sanitized Equipment Rentals (Beds, Oxygen, BiPAP, Wheelchairs), and Recovery Milestone Tracking.
- 🗄️ **ABDM-Aligned Personal Health Vault:** 256-bit encrypted digital vault for prescriptions, lab reports, vaccination certificates, and discharge summaries with granular consent controls.
- 👨‍👩‍👧 **Real-Time Family Care Dashboard:** Live coordination portal for permitted loved ones to view upcoming doctor visits, nurse logs, vitals telemetry, and medicine compliance.
- 🏢 **Healthcare Provider Portal:** Dedicated console for hospitals, physicians, ambulance operators, and equipment vendors to manage availability, triage patient requests, and track analytics.
- 🗺️ **Interactive Geo-Spatial Discovery:** Multi-city support (Bengaluru, Mumbai, Delhi NCR, Hyderabad, Chennai, Pune) with interactive radar maps and nearby healthcare provider pins.
- 📅 **Universal 5-Step Booking Wizard:** End-to-end booking flow with slot selection, patient info, instant confirmation slips, Google Calendar integration, and celebration feedback.

## 🛠️ Tech Stack & Architecture

- **Frontend Core:** [React 19](https://react.dev/) + [Vite 8.3](https://vitejs.dev/)
- **UI & Iconography:** [Lucide React](https://lucide.dev/) (Comprehensive medical & interface icons)
- **Styling & Design System:** Vanilla CSS3 with semantic CSS custom properties, glassmorphism, responsive grid/flexbox, and micro-animations
- **Celebration Effects:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio Feedback:** Custom Web Audio API synthesizer controller for pleasant UI feedback
- **Typography:** Google Fonts ([Inter](https://fonts.google.com/specimen/Inter) & [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans))
- **Data Architecture:** Fully typed mock datasets for Indian healthcare ecosystem (Fortis, Apollo, Manipal, Metropolis, Dr Lal, etc.)

## 🚀 Quickstart & Installation

### Prerequisites
- Node.js (v18.0 or higher recommended)
- npm or yarn or pnpm

### 1. Clone the repository
```bash
git clone https://github.com/apoorvkesarvani01-byte/mednest.git
cd mednest
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173/` or the URL printed in the terminal.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 5. Preview production build
```bash
npm run preview
```

## 🛡️ Safety, Legal & Regulatory Disclaimers

1. **Coordination Platform Notice:** MEDNEST is a healthcare coordination and discovery platform. MEDNEST does **NOT** diagnose medical conditions, prescribe medications, alter medicine regimens, or replace emergency medical services (EMS).
2. **Licensed Dispensing:** All prescription drugs require a valid digital or physical prescription authored by a registered medical practitioner (NMC). Fulfillments are handled exclusively by licensed pharmacy partners in strict compliance with the Drugs and Cosmetics Act.
3. **Emergency Situations:** In life-threatening emergencies, patients must immediately dial **112 / 108** or visit the nearest hospital emergency trauma center.
4. **Data Privacy & Consent:** All health records stored in My Health Vault adhere to Ayushman Bharat Digital Mission (ABDM) standards and are stored with 256-bit encryption. Data is shared exclusively with explicit patient consent.
